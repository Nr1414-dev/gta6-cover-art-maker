Vice Coast Cover Studio — an offline browser app that turns your photos and a caption into GTA 6-style multi-panel cover art: a nine-panel grid around a central VI logo, hero-and-three, four-panel, full-bleed and tilted-snapshot layouts; six gradient-map sunset and neon grades; per-panel photo crop and positioning; a halftone title block, neon script subtitle, badge ribbon and heat-meter stars. Exports PNGs at 1080 × 1080, 1080 × 1350 and 1920 × 1080. Photos never leave your machine, and every palm, skyline, sun, speedboat and helicopter on the cover is drawn by the app's own canvas code — no Rockstar logo, artwork or font.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
